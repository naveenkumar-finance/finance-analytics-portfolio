# Equity Portfolio Optimization using Modern Portfolio Theory

## Project Overview

This project focuses on constructing and analyzing an equity investment portfolio using Modern Portfolio Theory (MPT).

The objective was to analyze the risk and return characteristics of multiple stocks and build a diversified portfolio that optimizes the risk-return tradeoff.

The analysis includes calculating portfolio returns, volatility, beta, and risk-adjusted performance metrics.

---

## Dataset

The dataset contains historical stock price data for major technology companies including:

- Apple
- Microsoft
- Nvidia
- Amazon
- Tesla
- Meta
- Alphabet

Historical closing prices were used to calculate returns and portfolio risk metrics.

---

## Portfolio Construction

The portfolio was constructed by allocating weights across multiple stocks to achieve diversification.

Key steps performed:

1. Calculated daily and annual stock returns
2. Estimated volatility for each stock
3. Built correlation and covariance matrices
4. Allocated portfolio weights across assets
5. Calculated portfolio return and risk

---

## Risk & Return Analysis

The following portfolio metrics were calculated:

- Expected Portfolio Return
- Portfolio Volatility
- Beta
- CAPM Expected Return
- Sharpe Ratio

These metrics help evaluate the portfolio’s performance relative to market risk.

---

## Portfolio Performance

The final portfolio was compared with a benchmark index to evaluate performance.

Key comparisons included:

- Portfolio return vs market return
- Portfolio volatility vs market volatility
- Sharpe ratio comparison
