# Stock Market Data Analysis using SQL & Power BI

## Project Overview

This project analyzes historical stock price data using SQL queries and visualizes insights through an interactive Power BI dashboard.

The goal of the project was to understand stock price behavior, trading volume patterns, and price volatility using financial data analysis techniques.

---

## Dataset

The dataset contains historical stock market data with the following fields:

- Date
- Open Price
- High Price
- Low Price
- Close Price
- Trading Volume

These variables are commonly used in financial market analysis to evaluate price movements and market activity.

---

## SQL Analysis Performed

Several SQL queries were written to analyze stock market data.

Key analyses include:

- Average closing price
- Highest and lowest stock prices
- Daily price volatility (High – Low)
- Annual trading volume analysis
- Moving averages
- Daily return calculation

Example SQL operations used:

- SELECT
- GROUP BY
- ORDER BY
- Aggregate functions (AVG, MAX, MIN, SUM)
- Window functions (LAG, moving averages)

---

## Power BI Dashboard

A Power BI dashboard was built to visualize insights from the dataset.

The dashboard includes:

- Average closing price
- Maximum stock price
- Total trading volume
- Yearly trading volume trends
- Average price volatility by year

These visualizations help identify long-term stock price trends and market activity patterns.
