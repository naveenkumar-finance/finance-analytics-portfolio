# Three Statement Financial Model

## Project Overview
This project involves building an integrated three-statement financial model in Excel.  
The model links the Income Statement, Balance Sheet, and Cash Flow Statement to analyze a company's financial performance and forecast future financials.

The objective of this project was to understand how financial statements interact and how financial models are used in corporate finance and investment analysis.

---

## Financial Statements Modeled

### Income Statement
- Revenue
- Cost of Goods Sold
- Gross Profit
- Operating Expenses
- EBITDA
- Net Income

### Balance Sheet
- Current Assets
- Fixed Assets
- Liabilities
- Shareholder Equity

### Cash Flow Statement
- Operating Cash Flow
- Investing Cash Flow
- Financing Cash Flow

---

## Key Features

- Fully linked three-statement financial model
- Historical financial data analysis
- Financial forecasting for future years
- Dynamic financial statement linkage
- Automatic updates when assumptions change
