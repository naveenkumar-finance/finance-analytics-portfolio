# Financial Statement Analysis & DCF Valuation

## Project Overview
This project focuses on performing financial statement analysis and estimating the intrinsic value of a company using Discounted Cash Flow (DCF) valuation.

The analysis was performed on Procter & Gamble to evaluate financial performance, profitability trends, and determine whether the stock is fairly valued.

---

## Financial Analysis Performed

### Financial Statement Analysis
The following financial statements were analyzed:

- Income Statement
- Balance Sheet
- Cash Flow Statement

Key metrics analyzed:

- Revenue growth
- Profitability margins
- Operating income
- Net income trends

---

## Ratio Analysis

The following financial ratios were calculated:

### Profitability Ratios
- Gross Profit Margin
- Operating Margin
- Net Profit Margin

### Liquidity Ratios
- Current Ratio
- Quick Ratio

### Efficiency Ratios
- Inventory Turnover
- Receivables Turnover

### Valuation Ratios
- Price to Earnings (P/E)
- Dividend Yield

---

## Discounted Cash Flow (DCF) Valuation

DCF valuation was performed using the following steps:

1. Calculated Free Cash Flow to Firm (FCFF)
2. Estimated Weighted Average Cost of Capital (WACC)
3. Forecasted future cash flows
4. Calculated Terminal Value
5. Discounted future cash flows to present value
