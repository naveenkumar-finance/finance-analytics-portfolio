# Accounting Cycle Simulation

## Project Overview
This project demonstrates the complete accounting cycle using Excel.

The objective was to understand how business transactions flow through accounting records and are ultimately reflected in financial statements.

## Steps Performed

1. Recorded business transactions as journal entries.
2. Posted entries into T-accounts (ledger accounts).
3. Calculated adjusted balances.
4. Prepared the Income Statement.
5. Prepared the Balance Sheet.

## Skills Demonstrated

- Double Entry Accounting
- Journal Entries
- Ledger (T Accounts)
- Financial Statement Preparation
- Accounting Fundamentals

## Tools Used

- Microsoft Excel

## Key Learning

This project helped in understanding how accounting transactions flow into financial statements, which is essential for financial analysis and financial modeling.
